# Изменения

## 0.2.3 — подготовлена, не опубликована

- Контекст сокращается до JSON-сериализации с учётом места для черновика и
  инструкций. Длинные строки, JSON-экранирование и Unicode не нарушают JSON
  и лимит промпта в 13000 UTF-16 единиц.
- Лимит черновика согласован с редактором: 2000 UTF-16 единиц без разрыва
  surrogate pair. Некорректный внешний JSON-контекст отбрасывается.
- Подготовлен самостоятельный комплект: установщик, тесты, MIT, lockfile,
  TypeScript и GitHub Actions. Удалена привязка тестов к локальному temp-path.
- Автоматический режим по умолчанию сохранён. Подсказки принимаются целиком
  или по словам; существующие опции при обновлении сохраняются.
