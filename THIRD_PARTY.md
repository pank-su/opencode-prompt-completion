# Зависимости

Плагин использует публичные API OpenCode, OpenTUI и SolidJS. Их исходники и
бинарные модули не включены в этот репозиторий.

| Пакеты | Зафиксированная версия для разработки | Заявленная лицензия |
| --- | --- | --- |
| `@opencode/plugin`, `@opencode/theme` | `2.0.27` | MIT |
| `@opentui/core`, `@opentui/solid`, `@opentui/keymap` | `0.5.17` | MIT |
| `solid-js` | `1.9.12` | MIT |

Источники: [OpenCode](https://github.com/anomalyco/opencode),
[OpenTUI](https://github.com/anomalyco/opentui),
[SolidJS](https://github.com/solidjs/solid).

Для TypeScript, типов Bun и транзитивных dev-зависимостей действуют их
собственные лицензии. Установка зависимостей не передаёт их авторство автору
плагина. При отдельном распространении зависимостей сохраняйте требуемые
уведомления и тексты лицензий.
