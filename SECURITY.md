# Безопасность и приватность

Автоматическое дополнение включено по умолчанию. Недописанный текст и
ограниченный контекст диалога передаются модели до Enter. Установка плагина
не отменяет правил использования данных вашего провайдера или организации.
Для ручных запросов задайте `automatic: false` в опциях плагина.

Плагин выполняется локально с правами процесса OpenCode. Установщик меняет
глобальный `cli.json`, создаёт его резервную копию и копию релиза. Не
публикуйте личный конфиг, резервные копии или каталоги установленного OpenCode.

При сообщении об ошибке не прикладывайте API-ключи, credentials, рабочие
промпты и закрытые фрагменты истории. Диагностика «Статус автодополнения»
содержит счётчики и состояние, но имя провайдера и модели тоже может быть
чувствительным для вашей среды.

Не публикуйте подробности неисправленной уязвимости в обычном issue. Если в
репозитории доступен private vulnerability reporting, используйте его.
Иначе сначала попросите автора предоставить закрытый канал, без exploit и
чувствительных данных в публичном сообщении.
