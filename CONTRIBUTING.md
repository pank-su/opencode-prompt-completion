# Разработка

Для зафиксированного набора зависимостей нужны Node.js `26.7.0` и Bun `1.3.14`.

```sh
bun install --frozen-lockfile --ignore-scripts
bun run check
```

Отдельные проверки:

```sh
bun run test:unit
bun run test:renderer
bun run typecheck
```

Для исправления бага добавьте тест, проверьте падение до правки и успешный
запуск после неё. Для изменений редактора проверяйте виртуальный текст,
обычный ввод, принятие подсказки, Unicode, переносы и очистку при выгрузке.

Не добавляйте в тесты настоящие промпты, токены, внутренние адреса или
персональные пути. Используйте синтетические данные и временный каталог ОС.
Не меняйте установленный релиз во время разработки. Для отдельного тестового
конфига используйте `--config-dir` установщика.

Renderer-тесты не подтверждают работу с реальным провайдером или загрузку
плагина настоящим OpenCode. Такие проверки описывайте отдельно, с версией
OpenCode и платформой, без секретов и текста рабочей сессии.
